# Taller 360

Plataforma web neutra para gestión de talleres mecánicos.

## Prototipo
Abre `index.html` en un navegador o publica la rama `main` mediante GitHub Pages.

## Funciones actuales
- Identidad de empresa configurable.
- Clientes y vehículos vinculados.
- Historial de lecturas de odómetro.
- Órdenes de trabajo con subtareas, técnicos y prioridad.
- Vistas Lista, Kanban y Calendario.
- Planes de mantenimiento de referencia.
- Datos ficticios persistidos localmente (localStorage).

## Avisos
Esta es una maqueta en desarrollo. No utiliza Supabase ni autentica usuarios. No introduzcas datos reales de clientes. El repositorio público permite ver su código y la aplicación publicada podrá ser accesible a terceros.

## Próximas etapas
Fichas detalladas, costos por OT, presupuestos PDF, firma digital, permisos, alertas y conexión protegida a Supabase.
